# Migrating to 0.8.3

0.8.3 is a patch release of 0.8.2 with the same public surface, in preparation on `release/0.8.3`. It
repairs the findings the ten-pass adversarial review of the 0.8.2 candidate deferred
(`release-checklists/0.8.3-followups.md`, decision D-0217). No name is added, renamed, or removed, and
every 0.8.2 pickle, JSON model and checkpoint loads unchanged. This guide lists, by surface, every repair
that makes an input 0.8.2 accepted and mis-scored in silence raise or warn instead; the list is empty until
the first such repair lands.

## Nothing raises differently yet

No repair on `release/0.8.3` changes what an input does. The previous patch's list is in the
[0.8.2 migration guide](0.8.2.md).
