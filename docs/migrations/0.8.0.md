# Migrating to 0.8.0

Status: development draft; 0.8.0 is not yet published.

## Input validation

Quantitative semantics, calibration, posterior schemas, MinHash controls, law
discovery, and sequential-design budgets reject malformed, non-finite, or
out-of-range values earlier. Callers that relied on silent acceptance must
validate inputs and handle ValueError at the public boundary.

The same tightening now covers several previously-silent numerical and shape
cases:

* `WishartDistribution`, `InverseWishartDistribution`, `MatrixNormalDistribution`,
  and `NormalWishart` reject a non-symmetric or non-positive-definite matrix
  argument instead of accepting it and producing a downstream NaN or a
  misleading log-density.
* The Gaussian and Student-t copulas, and `LKJDistribution`, reject a
  correlation-like matrix argument that is not symmetric, does not have a unit
  diagonal, or is not positive definite.
* `GaussianBelief` rejects an indefinite covariance matrix; `CategoricalBelief`
  rejects a `labels` argument whose length does not match the probability
  vector.
* Conformal prediction (`weighted_conformal` and the underlying quantile
  routine) rejects `n=0` and negative calibration or test weights instead of
  returning a degenerate or silently-wrong interval.
* `mixle.epistemic.discrepancy.mmd` rejects empty samples and a non-positive
  bandwidth.

Callers constructing these objects from external or previously-unvalidated
data must catch `ValueError` at the construction boundary rather than relying
on the object silently accepting an invalid input.

## Self-evolution verify gate

`mixle.evolve.verify.Verdict.calibration_status` replaces the previously
implicit pass/fail calibration check with an explicit three-state string:
`"passed"`, `"failed"`, or `"unavailable"` (calibration could not be computed
for this model pair, or was not requested -- this does not block promotion,
same as `"passed"`). `Verdict.calibrated` remains available as a derived
property (`calibration_status != "failed"`), so existing code that reads
`verdict.calibrated` or `verdict.as_dict()["calibrated"]` is unaffected;
`as_dict()` additionally now includes `calibration_status`. Separately, the
non-nested cross-check that `challenger_beats_champion(..., nonnested=True)`
runs now downgrades the verdict to `"tie"` if the cross-check itself raises,
rather than letting an unrelated earlier verdict stand unverified -- code that
asserted a promotion decision purely from the paired test, ignoring a raised
cross-check, may see a different (safer) outcome.

## Empirical law discovery

Candidate forms are selected on a validation split and the winner is confirmed
on an untouched holdout split. The result adds selection_r2 and n_selection.
ranking contains validation scores; holdout_r2 determines passed. Code that
interpreted ranking values as final confirmation scores must update.

## Sequential-design budgets

max_rounds means the maximum adaptive acquisitions after the initial fit, so a
completed trace can contain max_rounds + 1 fitted states. Negative,
non-integral, and boolean budgets are rejected.

## Imports and tests

The root lazy namespace translates only a genuinely absent requested submodule
to AttributeError; a missing dependency inside an existing module now
propagates with its original cause. Pytest collects both supported filename
conventions, which may expose previously skipped tests in custom automation.

## Rollback

Pin the previous supported release and restore artifacts produced by its
compatible schemas. Do not suppress new validation errors without confirming
that the prior accepted behavior was scientifically meaningful.
