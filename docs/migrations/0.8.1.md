# Migrating to 0.8.1

0.8.1 is the first published release of the 0.8 line: the 0.8.0 candidate tree plus the
post-candidate fixes in the changelog, released under a new version because 0.8.0 was never
published (decision D-0212). Every migration step for the 0.8 line is in the [0.8.0 guide](0.8.0.md);
follow it as written, reading `0.8.0` as `0.8.1`. No public API changed between the 0.8.0 candidate
and 0.8.1; the new `win_probability`/`tie_probability` methods on the paired-comparison families and
the `strongly_connected` diagnostics field are additions.
